# Experimental mockups

Design mockups that we keep for reference. Nothing here ships or builds; each file is a self-contained HTML page with inline data.

- `deck-box-opens.html`: a Lift Deck layout with a vertical flow column. The current function opens into a wide code box. It shows the 25 steps of `flow-import-overview`. Keys: `k` forward, `j` back, `f` full screen code, `m` minimize code, `c` compact, `?` keys, `esc` back to normal.
